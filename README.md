# Only You v0.1

A compact, replayable psychological-romance visual novel prototype designed for iPhone Safari.

## Included
- Random heroine name and hidden archetype
- Seven-day procedural run
- Variable event deck
- Hidden affection, trust, suspicion, fear, dependence, awareness, and morality
- Multiple endings
- Autosave and continue
- Home Screen / PWA support
- Offline cache after first load

## iPhone deployment
1. Create a GitHub repository.
2. Upload every file in this folder to the repository root.
3. Enable GitHub Pages from the main branch.
4. Open the Pages link in Safari.
5. Use Share > Add to Home Screen.

The prototype is intentionally compact. It is the engine seed, not the full game.
